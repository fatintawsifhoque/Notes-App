# 📝 My Notes – A Simple & Beautiful Note-Taking App

> "Your thoughts matter — save them before they fade."  
> A lightweight, responsive note-taking app built with **Vue 3** and **Tailwind CSS**. Everything you write stays **saved in your browser** — even after refresh!


## ✨ Features

- ✅ **Add notes** with title and content 
- ✅ **Delete notes** with one click  
- ✅ **Persistent storage** — notes are saved in your browser using **localStorage**
- ✅ **Fully responsive** — works beautifully on mobile, tablet, and desktop  
- ✅ **Timestamps** — see exactly when you saved each note 
- ✅ Zero dependencies — just Vue + Tailwind
- ✅ Smooth animations & modern UI with Tailwind
